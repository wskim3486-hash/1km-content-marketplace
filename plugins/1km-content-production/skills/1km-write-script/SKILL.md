# 1km 대본 작성

## 필수 참고

작성 전에 [references/script-style-guide.md](references/script-style-guide.md)와 [references/ai-break-dialogue.md](references/ai-break-dialogue.md)를 읽고 종결어미, 말맛 장치, 생활 장면, 30초 오프닝, AI 환기 대화, 화면·그래픽 근거 링크 기준을 적용한다.

## 입력 제한

승인된 구성안과 A·B 등급 팩트만 사용한다. 자료가 부족하면 빈틈을 상상으로 메우지 말고 필요한 추가 취재를 표시한다.

## 목소리

진행자가 시청자 옆에서 함께 궁금해하고, 놀라고, 반박하고, 하나씩 확인해 주는 태도로 쓴다. 뉴스 문어체보다 상호작용형 대화체를 쓰되 사실의 무게는 유지한다. 레퍼런스 진행자의 고유 말버릇이나 문구를 복제하지 않는다.

문장을 존댓말 하나로 통일하지 않는다. 설명은 `~다/~야`, 호응은 `~요/~죠/~거든요`, 질문과 전환은 `~까/~냐/~건가`를 섞는다. `~습니다/~입니다`는 공식 수치나 강한 정리에만 제한적으로 사용한다. 이는 시청자에게 직접 반말하거나 무례하게 말하라는 뜻이 아니다.

## 작성 규칙

1. 오프닝을 인사보다 장면과 질문으로 시작한다.
2. 한 문장에 한 정보만 담고 소리 내 읽기 쉬운 길이로 쓴다.
3. `질문·주장 → 근거·사례 → 진행자 반응 → 쉬운 번역 → 반론·다음 질문`으로 문단을 전개한다.
4. 핵심 숫자는 가급적 세 개 이내로 남기고 비교 기준을 말한다.
5. 사실 `[F01]`, 해석 `[해석]`, 사례 `[사례]`, 화면 `[화면]`, 그래픽 `[그래픽]`을 초고에 표시한다.
6. 개별 사례의 대표성 한계와 반례를 자연스럽게 포함한다.
7. 결론에서 처음 질문에 직접 답하고 과장 없는 관찰 포인트를 남긴다.
8. 모든 `[화면]`과 `[그래픽]` 지시 바로 아래에 해당 멘트를 뒷받침하는 `[근거링크: 출처명·자료명·발행일 | 직접 URL]`를 붙인다.
9. 공식 통계·법령·공공기관 자료가 있으면 기사보다 원자료 링크를 우선한다.
10. 검색 결과 URL이 아니라 실제 공식자료·기사·게시물 원문 URL을 사용한다.
11. 출처표를 본문 팩트 ID와 화면·그래픽 지시에 연결한다.
12. 전체 낭독 문장의 70% 이상을 대화형 종결로 쓰고, `~습니다/~입니다/~합니다/~됩니다` 계열은 20% 이내로 제한한다.
13. `~습니다` 계열 또는 같은 종결어미가 3문장 연속 나오면 문장 기능에 맞는 다른 어미로 다시 쓴다.
14. 대본을 완성한 뒤 종결어미를 점검한다. 기자 리포트체가 우세하면 제출하지 말고 전체 리듬을 교정한다.
15. 첫 30초 안에 질문 한 번과 반응·반전·예상 반론 중 하나를 포함해 상호작용 비트를 두 번 이상 둔다.
16. 본문에서 정보 설명만 이어지는 구간이 45초를 넘지 않게 하고, 보통 3~6문장마다 질문·반응·반론·발견 중 하나를 배치한다.
17. 추임새·감탄사 뒤에는 새 정보·질문·반론 중 하나를 이어 붙인다. 의미 없이 붙은 `아니`, `자`, `그렇죠`, `솔직히`, `사실`, `그러니까`는 지운다.
18. 같은 추임새나 접속 문구를 90초 안에 반복하지 않고, 강한 감탄사는 한 문단에 하나를 넘기지 않는다.
19. `아마도`는 `[해석]`에만 사용하고, 사실의 빈틈을 얼버무리는 용도로 쓰지 않는다.
20. `니네/너네`처럼 시청자를 낮출 수 있는 호칭은 기본 대본에서 쓰지 않는다. 진행자 캐릭터와 채널 합의가 따로 있을 때만 검토한다.
21. 검증된 생활 공감 장면 2~3개를 서로 다른 구간에 배치한다. 장면은 사람의 선택·행동·사물·공간으로 보여주고 곧바로 숫자를 덧씌우지 않는다.
22. 통계·정의·구조 설명 문단을 두 개 연속 배치하지 않는다. 핵심 숫자 뒤에는 진행자 반응, 쉬운 뜻, 생활 장면 중 하나를 둔다.
23. 실제 인물의 말·감정·가족관계를 확보하지 않았다면 직접인용처럼 쓰지 않는다. 복수 사례의 공통 장면은 `[재구성]`, 계산용 상황은 `[가상예시]`로 밝힌다.
24. 8분 기준 AI 쉬어가기 2회를 기본으로 하되, 자연스러운 자리가 하나뿐이면 1회로 줄인다. 회당 편집본 10~20초, 전체 40초 이내로 설계한다.
25. 기자는 직전 내용의 단어·사물에서 나온 시시콜콜한 질문을 던진다. 결과·전망·원인 분석·정책 평가를 AI에게 묻지 않는다. AI 쉬어가기는 기자와 2~4번 짧게 주고받고, 기자의 복귀 멘트는 다음 팩트로 바로 이어져야 한다.
26. AI는 새 통계·정책 판단을 설명하는 해설자가 아니라 질문 속 익숙한 단어 하나를 잘못 붙잡고 과잉 보고하는 `의욕만 넘치는 신입 AI`다. 첫 오해를 정정받은 뒤 인접한 방향으로 한 번 더 빗나갈 수 있으나, 연결고리가 즉시 이해돼야 한다. 사람·피해·취약성을 웃음거리로 삼지 않고, 실제 제품·업체·인물에 관한 확인되지 않은 정보를 만들지 않으며, 사실처럼 들리는 AI 답변은 게시 전 검증한다.

## 작성 순서

1. 검증된 사실과 해석으로 팩트 골격을 쓴다.
2. 각 문단에서 시청자가 속으로 할 법한 반응을 하나 정한다.
3. 필요한 곳에 질문·공감·놀람·양보·발견·자기대화를 넣어 말맛 레이어를 만든다.
4. 숫자·분석 블록 사이에 검증된 생활 장면을 넣고, 장면이 결론을 대신 증명하지 않도록 대표성 한계를 지킨다.
5. AI 쉬어가기의 진입 질문·응답 방향·기자 반응·복귀 멘트를 설계한다.
6. 소리 내 읽고 연기해야만 살아나는 문장과 습관성 추임새를 덜어낸다.
7. 첫 30초, 45초 설명 독주, 통계 문단 연속, 90초 내 문구 반복, AI 대화 총 길이를 점검한다.

## 출력

[references/script-format.md](references/script-format.md)를 따른다. 최종 낭독본과 근거 링크가 포함된 내부 제작본을 구분하고 예상 러닝타임을 적는다. 메인 대본에는 기자 질문·삽입 표시·복귀 멘트를 넣고, 실제 AI 응답 운용은 별도 `AI 쉬어가기 촬영안`으로 작성한다. 내부 제작본 끝에 `첫 30초 상호작용`, `45초 이상 설명 독주`, `통계 문단 연속`, `생활 장면 분산`, `반복 추임새`, `AI 대화 진입·복귀`를 확인한 리듬 진단을 붙인다. 완성본은 반드시 `1km-script-fact-check` 단계로 넘긴다.
