# 6단계: 1km 작가용 대본 스타일 가이드

버전: 2.1  
상태: 간다효 자막 6편 및 1km 하원알바 대본 비교 분석, 말맛·상호작용 장치 보강

## 대본의 목소리

기자가 완성된 뉴스 원고를 읽는 목소리가 아니다. 잘 아는 사람이 시청자 옆에서 “이게 왜 이런지” 같이 따져보는 상호작용형 대화체다. 사실은 정확하게 말하되 문장 끝은 `~습니다`로 정렬하지 않는다. 정보를 말한 뒤 바로 다음 정보로 넘어가지 말고, 시청자가 속으로 할 법한 반응·의문·반론을 진행자가 중간중간 대신 꺼낸다.

중요한 구분은 다음과 같다.

- 대화체는 가벼운 말장난이 아니라 듣는 사람의 다음 질문을 받아주는 말투다.
- `~다`, `~야`를 쓴다고 시청자에게 무례하게 말하는 것은 아니다.
- 반말 명령, 조롱, 욕설, 레퍼런스 진행자의 고유 말버릇은 가져오지 않는다.
- 사실의 엄밀함과 문장의 격식은 별개다. 정확한 팩트도 자연스럽게 말할 수 있다.
- 추임새와 감탄사는 장식이 아니라 집중을 다시 당기는 편집점이다. 의미 없이 문장마다 붙이지 않는다.

## 재분석 결과

제공된 간다효 자막 6편은 자동 전사라 문장부호와 오탈자가 있지만, 화법의 방향은 일관된다.

- 설명을 `~다`, `~야`, `~거예요`로 짧게 닫는다.
- 시청자와 호흡할 때 `~요`, `~죠`, `~잖아요`, `~거든요`를 쓴다.
- 다음 정보로 넘어갈 때 `왜 그럴까?`, `이게 뭐냐?`, `그럼 어떻게 되느냐?`처럼 질문한다.
- 공식적 사실이나 단호한 정리에서만 `~습니다`, `~입니다`가 간헐적으로 나온다.
- 한 문단 안에서도 평서·존댓말·질문을 섞어 리듬을 만든다.

자동 전사 토큰을 단순 집계한 참고치에서도 `~요` 989회, `~다` 557회, `~야` 393회, `~죠` 257회, `~까` 235회, `~냐` 102회가 잡혔다. 반면 기존 하원알바 대본은 `~습니다`, `~입니다`, `~합니다`, `~됩니다`가 대화형 종결보다 우세했다. 따라서 기존의 “구어체” 지시만으로는 부족하고 종결어미 운용을 명시적으로 제한해야 한다.

## 종결어미 운용표

| 기능 | 기본 어미 | 사용 예 | 주의 |
| --- | --- | --- | --- |
| 핵심 설명·쉬운 번역 | `~다`, `~야`, `~인 거다` | “이름은 하원 알바인데, 실제 일은 돌봄과 가사가 섞여 있는 거다.” | 시청자를 낮추는 직접 반말과 구분한다. |
| 공감·확인 | `~요`, `~죠`, `~잖아요` | “숫자만 보면 최저임금보다 높죠.” | 모든 문장을 `~요`로만 끝내지 않는다. |
| 이유·보충 | `~거든요`, `~는데요`, `~거예요` | “세 시간만 사는 게 아니거든요.” | 습관어처럼 연속 반복하지 않는다. |
| 질문·전환 | `~까?`, `~냐?`, `~건가?`, `~아닐까?` | “그런데도 왜 싸다고 느낀 걸까?” | 답을 바로 이어 붙여 전개 기능을 갖게 한다. |
| 공식 사실·강한 정리 | `~습니다`, `~입니다` | “2026년 최저임금은 시간당 1만320원입니다.” | 강조가 필요한 곳에서만 쓰고 두 문장 넘게 연속하지 않는다. |

## 어미 비율과 리듬 기준

- 전체 낭독 문장의 70% 이상을 `~다/~야/~요/~죠/~까/~냐/~거든요` 계열로 구성한다.
- `~습니다/~입니다/~합니다/~됩니다` 계열은 전체의 20% 이내를 권장한다.
- `~습니다` 계열이 3문장 연속 나오면 반드시 다시 쓴다.
- 같은 종결어미를 3번 연속 사용하지 않는다.
- 한 문단은 보통 `설명 → 쉬운 번역 → 질문` 또는 `질문 → 사실 → 반응` 리듬으로 만든다.
- 공식 수치 문장 하나를 `~입니다`로 닫았다면 다음 문장은 `~죠`, `~거든요`, `~다`, 질문형 중 하나로 바꾼다.

비율은 기계적으로 맞추기 위한 목표가 아니라 뉴스 리포트체로 회귀하는 것을 막는 안전장치다.

## 말맛의 기본 단위

대본의 기본 단위를 `정보 → 정보 → 정보`로 두지 않는다. 다음 두 리듬을 번갈아 쓴다.

- `질문 → 사실 → 진행자 반응 → 쉬운 번역 → 다음 질문`
- `시청자 예상 반응 → 반론·양보 → 새 사실 → 발견·반전`

여기서 진행자 반응은 새 팩트를 보태는 문장이 아니다. “잠깐, 이게 무슨 말이냐”, “숫자만 보면 괜찮아 보이죠”, “그런데 알고 보니 여기서 끝이 아니야”처럼 시청자가 생각을 정리할 틈을 만드는 한 박자다.

## 생활 장면으로 숨 고르기

숫자와 분석이 정확해도 계속 이어지면 시청자는 의미를 붙잡기 전에 지친다. 정보 블록 사이에 검증된 생활 장면을 넣어 숫자가 사람의 하루에서 무엇으로 보이는지 보여준다.

- 대본 전체에 생활 공감 장면 2~3개를 분산한다.
- 장면은 `누가 무엇을 선택하고, 무엇을 포기하거나 망설이는지`가 보이게 쓴다.
- 장면 하나를 꺼낸 직후 또 다른 통계표로 덮지 말고 진행자의 짧은 반응이나 질문으로 한 박자 둔다.
- 실제 사례 하나를 전체 추세의 증거로 쓰지 않는다. 구조는 통계가 설명하고 사례는 체감을 돕는다.
- 확보하지 않은 직접인용은 만들지 않는다. `[재구성]`과 `[가상예시]`는 낭독본에서도 자연스럽게 성격을 밝힌다.

기본 리듬은 `생활 장면 → 궁금증 → 핵심 근거 하나 → 쉬운 뜻 → 다음 장면`이다. 모든 문단을 이 공식으로 만들지는 않되, `통계 → 통계 → 분석 → 분석`이 이어지지 않게 한다.

## 말맛 장치 운용표

| 기능 | 표현 방향 | 변주 예시 | 사용 조건 |
| --- | --- | --- | --- |
| 시청자 호출·질문 | 말을 거는 질문 | “이거, 이상하지 않아요?”, “여기서 이런 생각 들죠?”, “그런데 그거 아세요?” | 답을 뒤에 회수할 때만 쓴다. |
| 공감·확인 | 예상 반응을 대신 말함 | “그렇죠.”, “숫자만 보면 괜찮아 보여요.”, “우리 입장에선 그렇게 느낄 만해요.” | 억지 동의를 강요하지 않는다. |
| 놀람·자기반응 | 정보의 체감 강조 | “아니, 잠깐만요.”, “와, 이건 좀 다르다.”, “솔직히 여기서 한 번 멈추게 돼요.” | 중대한 사고·피해를 희화화하지 않는다. |
| 반론·양보 | 시청자의 반박을 먼저 꺼냄 | “그렇다 치더라도…”, “아무리 그래도…”, “물론 이렇게 볼 수도 있어요.” | 바로 뒤에 근거나 한계를 붙인다. |
| 발견·전환 | 새 사실로 시선을 돌림 | “그런데 알고 보니…”, “근데 이게 끝이 아니야.”, “여기서 하나 더 봐야 돼요.” | 실제 새 정보가 있을 때만 쓴다. |
| 망설임·자기대화 | 복잡한 감정의 호흡 | “아, 이걸 뭐라고 봐야 할까.”, “솔직히 좀 헷갈리죠.” | 사실을 모른다는 뜻으로 쓰지 않는다. |
| 제한·추정 | 불확실성 표시 | “다만…”, “아마도 이 대목은…”, “현재 자료만 보면…” | `아마도`는 `[해석]`에만 쓰고 팩트처럼 단정하지 않는다. |
| 압축·강조 | 결론을 짧게 박음 | “그러니까 핵심은 이거야.”, “결국 시간보다 책임의 문제다.” | 같은 결론을 반복하는 용도로 쓰지 않는다. |

표현은 기능별 예시다. 특정 진행자의 어순·억양·고유 문구를 그대로 반복하지 말고, 주제와 진행자 성격에 맞게 매번 새로 쓴다.

## 배치와 밀도 기준

- 첫 30초 안에 최소 두 번의 상호작용 비트를 둔다. 하나는 질문, 다른 하나는 반응·반전·예상 반론 중 하나로 구성한다.
- 본문에 정보 설명만 이어지는 구간이 45초를 넘지 않게 한다.
- 보통 3~6문장마다 질문·반응·반론·발견 중 하나를 배치한다.
- 7~9분 대본 전체에 서로 다른 기능의 말맛 장치를 고르게 배치하되, 개수를 채우려고 의미 없는 감탄사를 넣지 않는다.
- 같은 문구를 90초 안에 되풀이하지 않고, 하나의 말맛 장치를 연속 두 문장에 쓰지 않는다.
- 한 문단에 강한 감탄사는 최대 하나만 둔다. 모든 정보에 놀라면 정작 중요한 정보가 약해진다.
- `그거 아세요?`, `아니`, `그렇죠`, `알고 보니` 같은 범용 표현도 매회 같은 위치에서 반복하지 않는다.
- `니네/너네`처럼 상대를 직접 낮출 수 있는 호칭은 기본 대본에서 쓰지 않는다. 진행자 캐릭터와 채널 합의가 따로 있을 때만 제한적으로 검토한다.
- 통계·정의·구조 설명 문단을 두 개 연속 배치하지 않는다.
- 핵심 숫자 뒤에는 사람의 선택·행동·사물·공간, 진행자 반응, 쉬운 번역 중 하나를 둔다.
- AI 쉬어가기는 정보가 빽빽해진 뒤나 관점이 전환되는 지점에 두되, 본문과 무관한 꽁트로 끊지 않는다.

## 30초 오프닝 리듬

첫 30초는 설명을 시작하는 구간이 아니라 시청자가 대화에 들어오는 구간이다.

1. 익숙한 장면 또는 직접 질문을 던진다.
2. 시청자가 할 법한 첫 반응을 진행자가 대신 말한다.
3. 예상과 다른 사실이나 충돌을 제시한다.
4. “그래서 오늘 확인할 질문”으로 이어간다.

예:

> 아이 한 명 데려오는 알바가 시급 1만4천 원이래요.  
> 딱 들으면, “어? 생각보다 괜찮은데?” 싶죠.  
> 그런데 잠깐만요. 이게 정말 20분 데려오는 값일까?  
> 알고 보니 부모가 사려는 건 시간이 아니라, 오후 4시의 빈칸이었다.

이 예시의 문구를 복사하지 말고 `호출 → 공감 → 충돌 → 질문`의 기능만 가져간다.

## 2회 작성 방식

1. **팩트 골격 작성:** 검증된 사실과 해석만으로 논리 순서를 완성한다.
2. **말맛 레이어 작성:** 각 문단에서 시청자의 예상 반응을 하나 정하고, 필요한 곳에 질문·추임새·양보·발견을 넣는다.
3. **과잉 제거:** 내용 없이 붙은 `아니`, `자`, `그렇죠`, `사실`, `그러니까`를 지운다.
4. **낭독 확인:** 진행자가 실제로 말할 때 자연스러운지 읽고, 연기해야만 살아나는 문장은 다시 쓴다.

말맛 레이어를 먼저 쓰면 팩트가 감정에 끌려갈 수 있다. 반드시 팩트 골격 뒤에 더한다.

## 핵심 화법

- 짧은 공감: “요즘 이런 글, 한 번쯤 보셨죠.”
- 질문: “그런데 왜 하필 지금 이런 알바가 생긴 걸까?”
- 확인: “그래서 실제로 그런지부터 봤어요.”
- 확장: “이걸 시급 이야기로만 보면 하나를 놓치게 된다.”
- 제한: “물론 이 사례 하나로 전체가 그렇다고 말할 수는 없어요.”
- 해소: “결국 시급 하나의 문제가 아니야. 하원 시간과 퇴근 시간이 어긋난 게 시작이다.”
- 반응: “아니, 잠깐. 숫자만 보면 괜찮아 보이는데 왜 계속 사람이 안 구해질까?”
- 양보: “그렇다 치더라도 시급이 최저임금보다 높잖아요. 그러면 다른 조건을 봐야겠죠.”
- 발견: “그런데 알고 보니 공고에 적힌 세 시간 밖에도 보이지 않는 시간이 있었다.”

예시는 기능을 보여주기 위한 것이며 매회 그대로 반복하지 않는다.

## 문장 규칙

- 한 문장에는 한 가지 정보만 담는다.
- 입으로 읽었을 때 15~25자 안팎의 짧은 문장을 기본으로 한다.
- 긴 기관명·제도명·통계는 먼저 쉬운 말로 설명하고 정확한 명칭을 붙인다.
- 숫자는 한 문단에 최대 두 개, 영상 전체의 핵심 숫자는 가급적 세 개 이내로 제한한다.
- 문단 끝에는 다음 궁금증·반응·정리 중 하나를 둔다.
- 접속어, 호응어, 같은 종결어미를 연속 사용하지 않는다.
- 추임새 뒤에는 새 정보·반론·질문 중 하나가 반드시 이어지게 한다.
- `아니`, `자`, `솔직히`, `사실`, `그러니까`를 습관적으로 문장 앞에 붙이지 않는다.
- “~에 따르면”, “~인 것으로 나타났습니다” 같은 기사 문장을 그대로 읽지 않는다.
- 문장을 무조건 존댓말로 통일하지 않는다. 의미와 리듬에 따라 평서·존댓말·질문을 섞는다.

## 사실과 해석 표시

초고에는 내부 표기를 사용한다.

- `[F01]`: 팩트체크를 통과한 사실
- `[해석]`: 자료에 근거한 해석
- `[사례]`: 대표성에 한계가 있는 개별 사례
- `[재구성]`: 복수의 확인된 사례에서 공통 상황만 합친 장면
- `[가상예시]`: 계산이나 구조 설명을 위한 가정
- `[AI 쉬어가기]`: 기자 질문과 AI 응답을 촬영할 환기 구간
- `[미확인]`: 대본 사용 금지 또는 추가 확인 필요
- `[화면]`: 자료화면·인터뷰 지시. 바로 뒤에 근거 링크를 표시한다.
- `[그래픽]`: 통계·비교·타임라인 등의 그래픽 지시. 바로 뒤에 원자료 링크를 표시한다.
- `[근거링크]`: 해당 멘트·화면·그래픽을 뒷받침하는 공식자료 또는 기사 원문 URL

최종 낭독본에서는 내부 표기를 제거하되 별도 출처표와 연결을 유지한다.

## 문단 구조

`질문 또는 주장 → 근거·사례 → 진행자 반응 → 쉬운 번역 → 반론 또는 다음 질문`

예:

> 하원 도우미 구인 글의 시급은 1만4천 원입니다. `[F01]`  
> 숫자만 보면 최저임금보다 높죠.  
> 아니, 그러면 꽤 괜찮은 알바 아닌가 싶잖아요.  
> 그런데 이 돈이 정말 아이를 데려오는 20분의 대가일까?  
> 이동과 대기, 안전 책임까지 붙으면 구인자가 사려는 건 시간보다 ‘안심’에 가깝다. `[해석]`
>
> `[화면: 실제 구인 글의 업무 조건 부분 확대]`  
> `[근거링크: 출처명·자료명·발행일 | https://...]`

## 구성별 작성 포인트

- 오프닝: 인사·채널 소개보다 장면, 반응, 질문으로 시작한다.
- 현상: 커뮤니티 반응만 나열하지 않고 실제 사례와 규모를 확인한다.
- 배경: 연표를 읽지 말고 지금 현상에 영향을 준 변화만 남긴다.
- 원인: 한 가지 이유로 단정하지 않고 중요도 순으로 2~3개를 설명한다.
- 반전: 앞선 설명의 한계나 예외를 대화형 질문으로 꺼낸다.
- 결론: 보고서식 요약을 반복하지 않는다. 처음 질문에 답하고 한 가지 질문이나 관찰 포인트를 남긴다.

## 촬영용 표기

- 호흡: `/`
- 의미상 강조: `[강조]`
- 어려운 발음: 괄호 안 발음 표기
- 화면 전환: `[화면: 내용]`
- 그래픽 지시: `[그래픽: 보여줄 수치·비교·단위]`
- 인터뷰 삽입: `[인터뷰: 대상/핵심 답변]`
- AI 대화 삽입: `[AI 쉬어가기 ①: 편집본 10~20초]`
- 출처 자막: `[출처자막: 기관·자료명·연도]`
- 근거 링크: `[근거링크: 출처명·자료명·발행일 | 직접 URL]`

## 화면·그래픽 근거 링크 규칙

- 모든 `[화면]`과 `[그래픽]` 지시 바로 아래에 최소 하나의 `[근거링크]`를 붙인다.
- 공식 통계·법령·공공기관 자료가 있으면 기사보다 원자료 링크를 우선한다.
- 사례 화면은 해당 기사 또는 게시물 원문을 연결하고 대표성 한계를 적는다.
- 링크는 검색 결과 페이지가 아니라 실제 자료 또는 기사 원문으로 연결한다.
- 하나의 화면이 여러 주장을 포함하면 근거 링크를 주장별로 구분한다.
- 링크가 없는 화면·그래픽 지시는 최종 내부 제작본에서 사용하지 않는다.

## 금지

- `~습니다/~입니다`로 대부분의 문장을 닫는 기자 리포트체
- 같은 종결어미 3회 연속 사용
- 확인되지 않은 내용을 재미를 위해 단정
- 기사 문장을 길게 베껴 읽기
- 시청자를 낮추는 반말 명령·비꼼·조롱
- 레퍼런스 진행자의 고유 문구·캐릭터·욕설 복제
- 정보와 연결되지 않는 감탄사·추임새 남발
- 숫자·통계·구조 설명 문단을 연속 배치해 청취 피로를 만드는 구성
- AI가 본문을 대신 해설하거나 웃음을 위해 새로운 사실을 지어내는 대화
- 피해자·취약계층·사고 당사자·특정 개인을 AI 농담의 대상으로 삼는 구성
- 모든 문단을 `그거 아세요?`, `아니`, `알고 보니`로 시작하는 공식화
- 불확실한 사실을 `아마도`로 얼버무리기
- 같은 결론을 여러 표현으로 반복해 시간을 늘리기
- 화면으로 보여줄 정보를 멘트로 전부 중복 설명

## 완성 기준

- [ ] 전체 낭독 문장의 70% 이상이 대화형 종결이다.
- [ ] `~습니다` 계열이 3문장 연속 나오지 않는다.
- [ ] 같은 종결어미가 3번 연속 나오지 않는다.
- [ ] 소리 내 읽었을 때 옆 사람에게 설명하듯 자연스럽다.
- [ ] 첫 30초 안에 질문과 반응·반전으로 구성된 상호작용 비트가 두 번 이상 있다.
- [ ] 정보 설명만 이어지는 구간이 45초를 넘지 않는다.
- [ ] 통계·분석 문단이 두 개 연속되지 않는다.
- [ ] 검증된 생활 공감 장면 2~3개가 서로 다른 구간에 배치됐다.
- [ ] 생활 장면과 실제사례·재구성·가상예시의 성격이 구분된다.
- [ ] AI 쉬어가기의 질문은 직전 내용에서 나오고 복귀 멘트는 다음 팩트로 이어진다.
- [ ] AI 대화가 회당 10~20초, 전체 40초 이내이며 억지 웃음이나 새 사실 설명에 기대지 않는다.
- [ ] 3~6문장마다 질문·반응·반론·발견 중 하나가 기능적으로 들어간다.
- [ ] 같은 추임새·접속 장치를 90초 안에 반복하지 않는다.
- [ ] 추임새를 제거했을 때 정보 연결이 더 좋아지는 문장은 과잉 표현으로 보고 정리했다.
- [ ] 1분 안에 핵심 질문이 나온다.
- [ ] 문단마다 정보 또는 감정의 진전이 있다.
- [ ] 팩트와 해석이 구분된다.
- [ ] 출처표와 팩트 ID가 일치한다.
- [ ] 모든 `[화면]`·`[그래픽]`에 직접 근거 링크가 있다.
- [ ] 완성 대본을 7단계 사후 팩트체크로 넘길 준비가 됐다.
- [ ] 7~9분 안에 읽힌다.
