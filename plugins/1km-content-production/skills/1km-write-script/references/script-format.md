# 촬영용 대본 형식

## 머리말

- 가제:
- 러닝타임 목표:
- 한 문장 질문:
- 한 문장 답:
- 진행자:
- 기준일:
- 사용한 팩트 ID:

## 표기

- 호흡: `/`
- 강조: `[강조]`
- 화면: `[화면: 내용]`
- 그래픽: `[그래픽: 보여줄 수치·비교·단위]`
- 인터뷰: `[인터뷰: 대상/핵심 답변]`
- 실제 사례: `[사례: 대상/상황/출처]`
- 복수 사례 재구성: `[재구성: 기반 자료]`
- 설명용 가정: `[가상예시: 가정 조건]`
- AI 대화: `[AI 쉬어가기 ①: 편집본 10~20초]`
- 출처 자막: `[출처자막: 기관·자료명·연도]`
- 근거 링크: `[근거링크: 출처명·자료명·발행일 | 직접 URL]`

모든 `[화면]`과 `[그래픽]` 바로 아래에 최소 하나의 `[근거링크]`를 붙인다. 링크가 없으면 해당 화면·그래픽 지시를 사용하지 않는다.

## 화법 점검

- 설명: `~다/~야/~인 거다`
- 공감·확인: `~요/~죠/~잖아요/~거든요`
- 질문·전환: `~까?/~냐?/~건가?`
- 공식 사실·강한 정리: `~습니다/~입니다`를 제한적으로 사용

전체 낭독 문장의 70% 이상을 대화형 종결로 구성한다. `~습니다` 계열 또는 같은 종결어미가 3문장 연속 나오면 교정한다. `~다/~야`는 설명형 평서에 쓰며 시청자를 향한 직접 반말 명령에는 쓰지 않는다.

## AI 쉬어가기 본문 표기

```text
기자: AI야, [직전 내용에서 자연스럽게 생긴 짧은 질문]
[AI 쉬어가기 ①: 편집본 10~20초]
기자: [AI 답변에 대한 짧은 실제 반응]. [다음 팩트로 돌아가는 복귀 멘트]
```

메인 대본에는 AI 답변을 확정 문장으로 쓰지 않는다. 아래 별도 촬영안에 응답 방향과 안전선을 적는다.
