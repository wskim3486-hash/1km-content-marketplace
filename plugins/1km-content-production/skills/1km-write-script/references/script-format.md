# 촬영용 대본 형식

## 머리말

- 가제:
- 러닝타임 목표:
- 선정 기사·기준일:
- 강한 사건:
- 시청자의 첫 판단:
- 판단을 흔드는 균열:
- 끝에서 갱신할 판단:
- 사용한 팩트 ID:

## 표기

- 기자 대사: `기자:`
- AI 대사: `AI:`
- 호흡: `/`
- 강조: `[강조]`
- 화면: `[화면: 내용]`
- 그래픽: `[그래픽: 수치·비교·단위]`
- 실제 사례: `[사례: 대상/상황/출처]`
- 복수 사례 재구성: `[재구성: 기반 자료]`
- 설명용 가정: `[가상예시: 가정 조건]`
- 출처 자막: `[출처자막: 기관·자료명·연도]`
- 근거 링크: `[근거링크: 출처명·자료명·발행일 | 직접 URL]`

모든 `[화면]`과 `[그래픽]` 바로 아래에 직접 원문 `[근거링크]`를 붙인다.

## 내부 제작본

장면마다 다음 순서를 사용한다.

```text
[장면 목적: 첫 판단/균열/조건 분해/답변/반례/회수 중 해당 기능]
[F01]
기자: 실제 낭독 대사
[화면: ...]
[근거링크: ...]
```

내부 제작본에는 출처를 충분히 남기되 기자 대사에서 `기사 속`, `같은 기사에는`, `기사에 따르면`, `이 기사에서는`을 반복하지 않는다.

## 최종 낭독본

기자와 AI가 실제로 읽을 완성 대사만 남긴다. 팩트 ID, 근거 링크, 제작 메모는 제거한다. 명확한 귀속이 꼭 필요한 주장만 자연스럽게 출처를 말한다.

## AI 쉬어가기

```text
[AI 쉬어가기: N=3]
기자: 직전 내용에서 자연스럽게 생긴 질문
AI: 익숙한 단어를 붙잡은 자신 있는 첫 오해
기자: 짧은 정정
AI: 인정 또는 선택적 재오해
기자: 다음 팩트로 돌아가는 복귀 멘트
```

자연스러운 1회를 기본으로 0~2회 사용한다. 한 장면은 2~5회 티키타카이며 기본값은 3회다. 빈칸 대사를 남기지 않는다.

## 제출 전 감사

- 강한 사건이 첫 30초에 등장하는가?
- 첫 판단→균열→판단 갱신이 들리는가?
- 확장 자료마다 `균열`·`답변`·`회수` 기능이 있는가?
- 처음 사건을 엔딩에서 회수했는가?
- 약 3분의 1 기사 중심성이 별도 파트 없이 살아 있는가?
- 낭독 대사에서 불필요한 기사 호명이 제거됐는가?
- 브랜드가 사라지거나 홍보처럼 반복되지 않는가?
- 문장 전체가 실제 입말로 다시 쓰였는가?
- 소리 내 읽기 결과가 자연스러운가?
- 신입 AI가 설명자가 되지 않고 본문으로 복귀하는가?
