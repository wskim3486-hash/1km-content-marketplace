# 5단계: 7~9분 구성안 작성 가이드

버전: 1.0

## 목적

검증된 취재 재료를 시청자의 궁금증이 커졌다가 자연스럽게 해소되는 순서로 배열한다.

## 기본 구조

| 구간 | 권장 시간 | 역할 |
| --- | --- | --- |
| 콜드 오픈 | 0:00~0:25 | 익숙하지만 이상한 장면·사실로 즉시 공감 유도 |
| 질문 고정 | 0:25~0:55 | 오늘 풀 질문과 시청 이유를 한 문장으로 제시 |
| 현상 확인 | 0:55~2:00 | 실제 사례·숫자로 “정말 그런가” 확인 |
| 배경 확장 | 2:00~3:30 | 언제부터, 무엇이 달라졌는지 설명 |
| 원인 해부 | 3:30~5:30 | 원인 2~3개를 근거와 사례로 연결 |
| 반전·예외 | 5:30~6:40 | 단순 결론을 깨는 반례·이해관계 제시 |
| 해소 | 6:40~7:50 | 처음 질문에 명확하지만 과장 없는 답 제시 |
| 생활 연결·엔딩 | 7:50~9:00 | 시청자에게 남는 의미와 관찰 포인트 제시 |

시간은 주제에 따라 조정하되, 질문 제시는 1분을 넘기지 않는다.

## 장면 단위 작성법

각 장면은 다음 여섯 요소를 가진다.

1. 장면 목적
2. 진행자 핵심 멘트와 예상 종결어미 리듬
3. 근거가 되는 팩트 ID
4. 보여줄 화면
5. 다음 장면으로 넘기는 질문 또는 연결 문장
6. 예상 시간

## 구성안 양식

| 구간·시간 | 장면 목적 | 핵심 내용 | 팩트 ID | 화면·그래픽 | 연결 장치 |
| --- | --- | --- | --- | --- | --- |

구성표 아래에 작성한다.

- 영상의 한 문장 질문:
- 영상의 한 문장 답:
- 가장 강한 훅:
- 중간 반전 또는 새 정보:
- 반드시 남길 숫자 최대 3개:
- 대본에 넣을 생활 공감 장면 2~3개:
- 숫자·분석 뒤에 붙일 쉬운 생활 번역:
- AI 쉬어가기 2곳의 진입 질문·웃음 기능·복귀 멘트:
- 삭제해도 되는 보조 정보:
- 엔딩에서 남길 관찰 포인트:

## 간다효 레퍼런스 반영 원칙

- 정식 뉴스 문어체보다 대화하듯 질문을 던진다.
- 한 번에 결론을 말하지 않고, 시청자의 다음 질문을 선제적으로 받아 전개한다.
- 사례 → 질문 → 배경 → 더 큰 맥락 → 처음 질문의 해소 순서를 우선한다.
- 정보 사이에 짧은 반응과 전환을 넣되 억지 유행어는 만들지 않는다.
- 통계·분석 블록을 두 구간 연속 배치하지 않는다. 숫자를 말한 뒤에는 사람의 선택·행동·생활 장면 또는 쉬운 뜻으로 호흡을 바꾼다.
- AI 대화는 직전 문장의 궁금증에서 시작하고 다음 사실로 돌아오는 연결 장치로만 쓴다.
- 설명은 `~다/~야`, 호응은 `~요/~죠`, 전환은 `~까/~냐`처럼 기능에 따라 어미를 섞는다.
- 구성안부터 `~습니다` 계열이 연속되는 핵심 멘트를 만들지 않는다.
- 레퍼런스의 고유 문구·말버릇을 복제하지 않고 구조와 기능만 참고한다.

이 기준은 제공된 간다효 자막 6편의 화법 재분석을 반영했다. 상세 종결어미 운용과 금지 규칙은 `07_대본_작성_스타일가이드.md`를 따른다.

## 검수 질문

- [ ] 30초 안에 시청자가 자기 이야기처럼 느끼는가?
- [ ] 1분 안에 질문이 명확해지는가?
- [ ] 각 구간이 앞 구간과 다른 정보를 주는가?
- [ ] 중간에 예상 밖의 사실이나 반례가 있는가?
- [ ] 결론이 처음 질문에 직접 답하는가?
- [ ] 모든 사실에 팩트 ID가 연결됐는가?
- [ ] 핵심 멘트가 `~습니다` 중심의 뉴스 리포트체로 설계되지 않았는가?
- [ ] 검증된 생활 공감 장면 2~3개가 서로 다른 구간에 배치됐는가?
- [ ] 통계·분석 구간이 두 번 연속되지 않는가?
- [ ] AI 쉬어가기의 진입과 복귀가 본문 흐름에 붙어 있는가?
