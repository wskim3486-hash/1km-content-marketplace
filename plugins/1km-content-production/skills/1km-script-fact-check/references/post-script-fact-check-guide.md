# 7단계: 대본 완성 후 2차 팩트체크 검증표

버전: 1.0  
기준일: 2026-08-20

## 목적

1차 팩트체크를 통과한 자료가 대본 문장으로 바뀌는 과정에서 생길 수 있는 과장·누락·맥락 변화·숫자 오류·링크 불일치를 녹화 전에 다시 잡는다.

## 검증 대상

- 사실처럼 들리는 모든 대본 문장
- 숫자·날짜·비율·순위·금액·인용
- 원인과 결과를 연결하는 문장
- 사례를 전체 현상으로 확장하는 문장
- `[화면]`·`[그래픽]`·`[출처자막]`·`[근거링크]`
- 대본 완성 이후 바뀔 수 있는 최신 정보
- 실제사례·재구성·가상예시의 유형 표시와 대표성 한계
- 최종 편집에 사용할 AI 답변 중 사실처럼 들리는 문장

## 검증 절차

1. 대본을 문장 단위로 나누고 S001부터 문장 ID를 부여한다.
2. 각 사실 문장을 기존 팩트 ID와 연결한다.
3. 연결된 근거 링크를 직접 열어 제목·기관·발행일·본문 내용을 다시 확인한다.
4. 대본 표현이 출처가 말하는 범위보다 강해지지 않았는지 비교한다.
5. 숫자와 인용을 원문과 한 글자·한 단위씩 대조한다.
6. `[화면]`·`[그래픽]` 내용이 대본 주장과 같은 사실을 보여주는지 확인한다.
7. 녹화일 기준으로 바뀐 사실이 없는지 최신 자료를 확인한다.
8. 오류 문장을 수정하고 수정본을 같은 절차로 재검증한다.
9. AI 답변의 사실 문장을 검증할 수 없으면 해당 답변을 최종 편집에서 제거한다.

## 판정

- `PASS`: 출처와 문장이 정확히 일치하고 근거 링크가 정상 작동한다.
- `REVISE`: 근거는 있으나 과장·누락·맥락·단위 오류가 있어 수정해야 한다.
- `HOLD`: 출처 충돌 또는 최신성 문제로 추가 확인이 필요하다.
- `REMOVE`: 근거가 없거나 사실과 달라 대본에서 삭제한다.

## 통과 조건

- [ ] 사실처럼 들리는 모든 문장이 검증표에 포함됐다.
- [ ] 모든 `[화면]`·`[그래픽]`에 직접 근거 링크가 있다.
- [ ] 모든 링크가 정상적으로 열리고 해당 주장을 직접 뒷받침한다.
- [ ] `REVISE` 항목은 수정 후 재검증됐다.
- [ ] `HOLD`와 `REMOVE`가 최종 대본에 남아 있지 않다.
- [ ] 사례 유형이 공개됐고 확보하지 않은 직접인용이 없다.
- [ ] 사용할 AI 답변의 사실 문장이 검증됐거나 편집에서 제거됐다.
- [ ] 검증 기준일과 확인시각을 기록했다.
- [ ] 최종 판정이 `2차 팩트체크 통과`다.
