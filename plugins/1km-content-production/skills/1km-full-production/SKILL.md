# 1km 전체 제작 총괄

선정 기사를 중심 기둥으로 고정하되, 최종 낭독에서는 출처 관리 과정이 아니라 한 편의 이야기가 들리게 만든다. 시작의 첫 판단을 딥리서치로 흔들고 처음 사건으로 돌아와 판단을 갱신한다.

## 필수 참고

작업 전에 [승인된 서사 기준](../../references/approved-narrative-standard.md)과 [전체 제작 파이프라인](references/pipeline.md)을 모두 읽는다.

## 실행 범위

- 사용자가 후보나 기사를 지정하고 `이걸로 진행해`라고 하면 그 지정을 승인으로 간주해 3~8단계를 연속 실행한다.
- 사용자가 탐색만 요청하면 `1km-find-items`만, 선정까지 요청하면 `1km-find-items`와 `1km-select-item`까지만 실행한다.
- 아이템 선택까지 맡긴 전체 제작은 자동 선정을 명시적으로 허용한 경우에만 1~8단계를 연속 실행한다.

## 제작 순서

1. `1km-find-items`: 최신 뉴스 랭킹 근거가 있는 비정치 후보 발굴
2. `1km-select-item`: 후보 비교와 최종 아이템 선정
3. `1km-research-topic`: 강한 사건, 첫 판단, 균열, 구조 분해, 비교 사례, 반례와 생활 딜레마를 조사
4. `1km-fact-check`: 대본 재료를 작성 전에 1차 검증
5. `1km-build-outline`: 승인된 이야기형 서사와 처음 사건 회수 설계
6. `1km-write-script`: 실제 구어체 촬영 대본, 내부 근거, 신입 AI 환기 대화 작성
7. `1km-script-fact-check`: 완성 대본과 화면·AI 사실 대사를 2차 검증
8. `1km-final-review`: 서사·낭독·화면·법적 위험 검수와 촬영 인계

선정 아이템에서 시작하면 1~2단계 산출물은 사용자가 제공한 정보로 대체하고 그 사실을 결과 머리말에 기록한다.

## 유지해야 할 원칙

- 0~9 결과물 구조와 대본 전·후 두 번의 팩트체크를 생략하지 않는다.
- 최신 뉴스·통계·정책·제도·법률은 원문을 확인하고 공식 1차 자료를 우선한다.
- 사실의 빈칸, 실제 인물의 말·감정·관계, 출처를 발명하지 않는다.
- 모든 화면·그래픽 바로 아래에 직접 근거 링크를 붙인다.
- 기사 직접 비중 약 3분의 1은 진단값으로만 쓴다. 별도 기사 파트를 만들거나 문장 수를 할당하지 않는다.
- `현상→배경→원인→반전→해소`를 고정 목차로 쓰지 않는다.
- 낭독 대사에서 `기사 속`, `같은 기사에는`, `기사에 따르면`, `이 기사에서는`을 습관적으로 쓰지 않는다. 출처는 내부 제작 정보와 자막으로 관리한다.
- 종결어미 비율, 문장 수 간격, 초 단위 간격을 말맛 공식으로 쓰지 않는다.
- AI는 `의욕만 넘치는 신입 AI`이며 본문 흐름에 자연스러운 1회를 기본으로 0~2회 사용한다.
- 정치 중심 아이템은 제작하지 않는다.

## 중단 조건

핵심 출처를 열 수 없거나, 독립 출처가 중대하게 충돌하거나, 법적·윤리적 위험이 해결되지 않거나, 확인되지 않은 사실을 발명해야만 진행할 수 있으면 완료 단계와 재개 조건을 보고하고 멈춘다.

## 최종 출력

[references/final-deliverables.md](references/final-deliverables.md)의 `0. 한눈에 보는 결론`부터 `9. 최종검수와 촬영 인계서`, `핵심 출처 모음`까지 순서를 유지한다. 촬영용 제작본과 최종 낭독본을 분리하고 마지막에 `GO / CONDITIONAL GO / HOLD / DROP`을 명시한다.
