# 1km 전체 제작 파이프라인

## 실행 분기

| 사용자 요청 | 실행 범위 | 승인 처리 |
|---|---|---|
| 오늘 아이템 찾아줘 | 1단계 | 후보만 제시 |
| 부동산 아이템 찾아줘 | 1단계 | 분야를 제한해 후보만 제시 |
| 추천 아이템 중 하나 골라줘 | 1~2단계 | 선정안을 제시 |
| 3번으로 진행해 | 3~8단계 | 지정 후보를 선정 승인으로 간주 |
| 이 주제로 대본까지 만들어줘 | 3~8단계 | 사용자 주제를 선정 승인으로 간주 |
| 아이템 선정부터 최종 대본까지 맡아줘 | 1~8단계 | 자동 선정을 명시적으로 허용한 경우만 연속 실행 |

## 단계별 인계 기준

| 단계 | 전용 스킬 | 필수 입력 | 필수 산출물 | 통과 기준 |
|---|---|---|---|---|
| 1. 발굴 | `1km-find-items` | 분야·제외 조건 | 후보 10개, 랭킹 서비스·종류·실제 순위·KST 확인시각·랭킹 페이지 | 정치 제외, 랭킹 페이지에서 기사 확인 가능 |
| 2. 선정 | `1km-select-item` | 후보 목록 | 점수표, 1순위 선정 브리프 | 7~9분 설명 가치와 검증 가능성 확보 |
| 3. 딥리서치 | `1km-research-topic` | 선정 브리프 | 강한 사건·첫 판단·균열·조건 분해·비교·반례·회수 지도, 생활 장면 후보 3개 이상 | 각 재료의 `균열`·`답변`·`회수` 기능, 출처와 대표성 한계 기록 |
| 4. 1차 팩트체크 | `1km-fact-check` | 취재노트 | 주장별 검증표, 사례 검증, 방송 가능 표현 | 핵심 주장과 수치가 검증되고 실제사례·재구성·가상예시가 구분됨 |
| 5. 구성안 | `1km-build-outline` | 검증 통과 취재노트 | 첫 판단→균열→조건 분해→확장→반례·딜레마→처음 사건 회수 구성안 | 기사 중심성이 별도 파트 없이 살아 있고 시청자의 판단이 갱신됨 |
| 6. 대본 | `1km-write-script` | 승인 구성안, 팩트체크 자료 | 낭독본, 내부 제작본, 출처표, AI 쉬어가기 촬영안 | 자연스러운 실제 구어체, 처음 사건 회수, 불필요한 기사 호명 제거, 신입 AI의 자연스러운 진입·복귀, 모든 화면·그래픽 근거 링크 |
| 7. 2차 팩트체크 | `1km-script-fact-check` | 완성 대본·링크·사용할 AI 답변 | 문장별 검증표, 링크 검증표, 수정 대본 | 본문과 AI 답변의 모든 사실 문장 PASS, REVISE 재검증, HOLD·REMOVE 없음 |
| 8. 최종검수 | `1km-final-review` | 2차 검증 통과본 | 교정본, 촬영 인계서, 최종 판정 | 논리·낭독·화면·법적 위험 검수 완료 |

## 연속 실행 규칙

1. 전체 제작 승인이 있으면 각 단계 통과 후 다음 단계로 바로 이동한다.
2. 각 산출물에는 확인 시각과 적용한 출처 상태를 남긴다.
3. 미확인 정보는 다음 단계에서 사실 문장으로 승격하지 않는다.
4. 앞 단계가 통과하지 못하면 뒤 단계의 완성물을 억지로 만들지 않는다.
5. 수정이 검증 가능한 범위라면 수정 후 해당 검증 단계부터 재실행한다.
