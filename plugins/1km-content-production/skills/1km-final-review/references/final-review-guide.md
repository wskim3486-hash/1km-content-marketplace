# 8단계: 최종검수 가이드

버전: 3.0

## 1. 사실 검수

- [ ] 2차 팩트체크가 PASS 또는 수정완료 상태다.
- [ ] 모든 사실 문장과 AI 사실 대사에 팩트 ID가 있다.
- [ ] 숫자의 시점·단위·모수가 정확하다.
- [ ] 인용과 귀속이 원문 의미와 같다.
- [ ] 사실·해석·실제사례·재구성·가상예시가 구분됐다.
- [ ] 녹화 시점에 바뀔 수 있는 내용을 재확인했다.

## 2. 승인 서사 검수

- [ ] 가장 강한 선정 기사 사건·인물·숫자·브랜드·충돌이 초반에 바로 나온다.
- [ ] 시청자의 쉬운 첫 판단이 분명하다.
- [ ] 그 판단을 흔드는 검증된 균열이 있다.
- [ ] 실제 조건·업무·비용·절차·사람의 선택이 장면으로 분해된다.
- [ ] 비교·역사·문화·구조 자료가 앞의 질문에 답한다.
- [ ] 반례·통계 한계·이해관계 충돌이 단순 결론을 막는다.
- [ ] 엔딩에서 처음 사건으로 돌아가 판단을 갱신한다.
- [ ] 약 3분의 1 기사 중심성이 문장 수 할당이나 별도 기사 파트 없이 살아 있다.
- [ ] 무관한 배경지식과 백과사전식 정보 나열이 없다.

## 3. 낭독 검수

- [ ] 소리 내 읽었을 때 한 사람이 내게 이야기를 들려주는 것처럼 들린다.
- [ ] `~습니다`를 `~다`로만 바꾸거나 빈 꼬리말을 붙인 문장이 없다.
- [ ] 같은 종결어미가 보고서처럼 이어진 곳은 문장 전체를 다시 말했다.
- [ ] 질문·반응·쉬운 번역·예상 반론이 실제 정보 변화가 있는 곳에 나온다.
- [ ] 어미 비율·문장 수·초 단위 간격을 합격 공식으로 사용하지 않았다.
- [ ] 최종 낭독에서 `기사 속`, `같은 기사에는`, `기사에 따르면`, `이 기사에서는`을 습관적으로 말하지 않는다.
- [ ] 꼭 필요한 귀속만 자연스럽게 말하고 출처는 자막과 내부 제작 정보에 남겼다.
- [ ] 브랜드·기업명이 공감과 이해에 필요한 만큼만 나오고 홍보처럼 반복되지 않는다.
- [ ] 생활 장면 2~3개가 서사상 필요한 곳에 있다.

## 4. AI 검수

- [ ] 본문 흐름에 자연스러운 1회 기본, 0~2회 범위다.
- [ ] 기자가 먼저 질문하고 AI가 익숙한 단어 하나를 자신 있게 오해한다.
- [ ] 정정과 복귀가 짧고 본문 설명을 대신하지 않는다.
- [ ] 사람·피해·취약성을 웃음거리로 삼지 않는다.
- [ ] 최종 편집에 남을 사실 대사가 2차 팩트체크에 포함됐다.

## 5. 화면·법적·윤리 검수

- [ ] 각 핵심 장면에 화면 계획이 있다.
- [ ] 모든 화면·그래픽 바로 아래에 직접 근거 링크가 있다.
- [ ] 그래픽의 축·단위·출처가 정확하다.
- [ ] 이미지·영상·게시물·아카이브의 사용 권리를 확인했다.
- [ ] 개인정보·미성년자·의혹·명예훼손 위험을 점검했다.

## 수정 우선순위

- P0: 사실 오류, 출처 없음, 중대한 법적·윤리적 위험
- P1: 첫 판단·균열·처음 사건 회수 실패, 기사 중심축 소실, 기사 낭독, 브랜드 홍보, 무관한 확장
- P2: 보고서체, 부자연스러운 입말, 반복, 통계 과밀, 생활 장면 부족, 억지 AI 대화
- P3: 취향·리듬·세부 표현

## 최종 판정

- `GO`: 녹화 가능
- `CONDITIONAL GO`: 표시된 P1 수정 후 녹화 가능
- `HOLD`: 추가 취재 또는 팩트체크 필요
- `DROP`: 제작 중단

2차 팩트체크에 `REVISE`·`HOLD`·`REMOVE`가 남아 있으면 `GO`를 부여하지 않는다.
