# 1km 프로젝트 운영 헌장

버전: 3.0

## 콘텐츠 약속

1km는 뉴스 요약 채널이 아니다. 이미 알려진 사건을 다시 읽는 대신, 시청자가 체감하지만 이유를 설명하기 어려운 현상을 한 걸음 더 들어가 풀어준다.

선정 기사는 콘텐츠의 핵심 기둥이다. 강한 사건에서 시청자의 첫 판단을 만들고, 딥리서치로 판단을 흔든 뒤, 처음 사건으로 돌아가 판단을 갱신한다. 최종 낭독에서는 기사라는 말을 반복하지 않는다.

## 시청자 경험

1. 사건: “어? 이게 뭐지?”
2. 첫 판단: “아, 이런 얘기구나.”
3. 균열: “그런데 그게 전부가 아니네?”
4. 발견: 조건·비교·반례를 보며 생각을 고친다.
5. 회수: 처음 사건이 다르게 보인다.

## 편집 원칙

- 가볍게 시작하되 내용은 가볍게 처리하지 않는다.
- 시청자를 가르치려 들지 않고, 함께 궁금해하는 태도를 유지한다.
- 한쪽 해석이 유리해도 반대 근거와 예외를 확인한다.
- 숫자는 비교 기준과 기간을 함께 말한다.
- 인과관계가 증명되지 않았으면 “영향을 줬을 가능성”, “함께 거론된다”처럼 범위를 제한한다.
- 개인 사례는 사례로만 쓰고 전체 현상으로 일반화하지 않는다.
- 아이템의 화제성은 기사 원문 링크가 아니라 뉴스 랭킹 페이지·순위·확인시각으로 증명한다.
- 대본 속 화면·그래픽 지시는 해당 문장의 근거 링크와 항상 붙여 쓴다.
- 대본 작성 전후로 팩트체크를 두 번 실시한다.
- 선정 기사의 가장 강한 사실·장면·갈등을 첫 30초 안에 사용한다. 약 3분의 1은 문장 수가 아니라 중심성 진단값이다.
- 확장 내용은 첫 판단을 흔들거나 앞의 질문에 답하고, 엔딩에서 처음 사건의 의미를 바꿔야 한다.
- 출처는 내부에서 철저히 관리하되 낭독 대사에서는 `기사 속`, `기사에 따르면` 같은 표현을 반복하지 않는다.
- 종결어미 비율은 대본 생성 공식이 아니라 보고서체 회귀를 찾는 사후 진단으로만 사용한다.
- AI는 `의욕만 넘치는 신입 AI`로 고정하며 기자가 항상 먼저 질문한다.

## 금지·주의 영역

### 항상 제외

- 정당·선거·정치인 중심 아이템
- 진영 대립과 이념 논쟁을 핵심 재미로 삼는 구성

### 표현 금지

- 근거 없는 확정적 예언
- 공포나 분노만 키우는 과장
- 출처 없는 통계와 금액
- 커뮤니티 반응을 여론 전체로 표현
- 기사 제목만 보고 원문과 다른 결론을 만드는 행위
- 특정 개인·업체를 불필요하게 식별하거나 비난하는 표현

## 역할

- PD: 주제·각 단계 승인, 취재 방향, 최종 편집 판단
- 리서치 역할: 자료 수집, 출처 기록, 미확인점 분리
- 작가 역할: 검증 자료만으로 구성안과 대본 작성
- 기자/진행자: 낭독하며 어색한 표현과 설명 부족 지점 피드백
- 2차 팩트체크 역할: 완성 대본의 문장과 근거 링크가 실제 출처와 일치하는지 재검증
- 최종 검수: 2차 팩트체크 통과 여부·법적 위험·논리·화면 구현 가능성 확인

## 출처 원칙

신뢰 우선순위는 `정부·공공기관·법령·원자료` → `학술·조사기관·기업 공식자료` → `신뢰도 높은 언론의 원문 취재` → `전문가 해설` → `커뮤니티·SNS` 순이다. 커뮤니티와 SNS는 화제 발견 및 사례 출발점으로만 사용하고, 사실 확정 근거로 단독 사용하지 않는다.
