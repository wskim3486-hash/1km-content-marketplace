# 1km 유튜브 콘텐츠 전체 제작 워크플로우

버전: 3.0
기준일: 2026-08-25

## 제작 목표

선정 기사의 강한 사건을 본 시청자가 쉬운 첫 판단을 내리고, 딥리서치로 그 판단이 흔들린 뒤, 처음 사건을 새롭게 보게 만든다.

## 고정 원칙

- 정치·정당·선거·정치인 공방·이념 대립은 아이템에서 제외한다.
- 경제·사회·세계·IT·생활 변화 중 시청자가 체감할 수 있는 주제를 우선한다.
- 화제성만 있는 사건보다 설명했을 때 새롭게 이해되는 현상을 고른다.
- 사실과 해석을 구분하고, 대본 작성 전 1차 팩트체크와 대본 완성 후 2차 팩트체크를 수행한다.
- 아이템 추천에는 기사 원문 링크가 아니라 네이버·네이트·다음의 랭킹 페이지와 확인 순위·시각을 제시한다.
- 촬영용 대본의 모든 `[화면]`·`[그래픽]` 지시에는 해당 멘트의 근거 링크를 붙인다.
- 대본보다 먼저 풍부한 딥리서치 취재노트를 만든다.
- 선정 기사는 콘텐츠의 핵심 기둥이다. 약 3분의 1은 중심성 진단값이며 별도 기사 파트나 문장 할당이 아니다. 낭독에서는 기사라는 말을 반복하지 않고 검증된 사건을 직접 이야기한다.
- 취재노트에는 출처가 있는 생활 공감 장면 후보와 숫자의 쉬운 생활 번역을 만들고, 대본에는 관련성 높은 장면 2~3개만 쓴다.
- AI 쉬어가기는 자연스러운 1회를 기본으로 0~2회 사용하며 기자가 먼저 질문한다.
- 현재 사용하는 ChatGPT·Claude·Gemini 기본 유료 플랜과 공개 자료 안에서 대본까지 완성하는 것을 우선한다.
- 영상 자동화·코딩은 실제 대본 한 편의 제작 방식이 검증된 뒤 확장한다.

## 단계와 통과 조건

| 단계 | 핵심 질문 | 필수 산출물 | 다음 단계 통과 조건 |
| --- | --- | --- | --- |
| 1. 아이템 발굴 | 지금 사람들이 무엇을 이야기하는가? | 후보 10개 목록 | 정치 제외, 랭킹 페이지·순위·확인시각 포함 |
| 2. 아이템 선정 | 지금 1km가 설명할 가치가 가장 큰 것은? | 평가표·1순위 추천 | 7~9분 확장 가능, 한 문장 질문 명확 |
| 3. 딥리서치 | 첫 판단을 무엇이 흔들고 처음 사건의 의미를 무엇이 바꾸는가? | 이야기형 취재노트 | 강한 사건·첫 판단·균열·조건 분해·비교·반례·회수, 생활 장면 후보와 출처 |
| 4. 1차 팩트체크 | 구성과 대본의 재료로 써도 되는가? | 주장별 검증표 | 핵심 주장 2회 이상 교차검증 |
| 5. 구성안 | 시청자의 판단이 실제로 움직이고 처음 사건으로 돌아오는가? | 타임코드 구성안 | 강한 사건→첫 판단→균열→조건 분해→확장→반례·딜레마→처음 사건 회수 |
| 6. 대본 | 한 사람이 내게 이야기를 들려주는 것처럼 들리는가? | 촬영용 대본·출처표·AI 촬영안 | 실제 구어체, 불필요한 기사 호명 제거, 판단 갱신, 신입 AI의 자연스러운 진입·복귀, 근거 링크 |
| 7. 대본 사후 팩트체크 | 완성 문장이 실제 출처와 정확히 일치하는가? | 문장별 2차 검증표·수정 대본 | 모든 사실 문장 PASS 또는 수정 완료 |
| 8. 최종검수 | 틀리거나 지루하거나 찍기 어려운 곳은 없는가? | 수정본·촬영 인계서 | 2차 팩트체크·흐름·낭독·화면 자료 검수 통과 |

## 표준 파일 흐름

`아이템_후보표` → `아이템_선정표` → `딥리서치_취재노트` → `1차_팩트체크_검증표` → `구성안` → `촬영용_대본` → `대본_사후_팩트체크` → `최종검수표_촬영인계서`

각 단계는 바로 전 단계의 승인본만 입력으로 사용한다. 앞 단계에 미확인 표시가 남아 있으면 다음 단계에서 사실처럼 쓰지 않는다.

## 사람의 최종 승인 지점

1. 후보 10개 중 실제 딥리서치할 아이템 선정
2. 딥리서치와 팩트체크 완료 후 제작 진행 여부 결정
3. 구성안 승인 후 대본 작성
4. 대본 완성 후 2차 팩트체크 결과 확인
5. 최종 대본 승인 후 기자 녹화

## 현재 파일럿 적용

- 파일럿: `당근 하원알바 시급 1만4천원`
- 검증할 핵심: 실제 게시물·시급 조건·업무 범위·지역 및 시점·유사 사례·돌봄 공백과 노동시장 맥락
- 특정 게시물 하나를 사회 전체의 보편 현상으로 확대 해석하지 않는다.
