# 1km 아이템 선정

## 필수 참고

평가 전에 [references/item-selection-guide.md](references/item-selection-guide.md)를 읽고 점수 기준과 승인 절차를 적용한다.

## 입력 확인

후보별 제목, 핵심 궁금증, 랭킹 서비스, 랭킹 종류, 실제 순위, KST 확인시각, 랭킹 페이지 링크를 확인한다. 랭킹 페이지에서 기사 제목을 다시 확인할 수 없는 후보는 보조 후보로 내리고, 정치 중심 후보는 평가 전에 제거한다.

## 평가

[references/scorecard.md](references/scorecard.md)의 가중치를 적용한다. 점수만 합산하지 말고 다음을 함께 판단한다.

- 1km가 기사 요약을 넘어 새 설명을 줄 수 있는가?
- 결론을 정해두지 않고 검증할 가설을 세울 수 있는가?
- 촬영·게시 시점에도 의미가 남는가?
- 자료·취재원·화면을 현실적으로 확보할 수 있는가?

## 출력

1. 전체 후보 점수표를 제시한다.
2. 1순위와 차순위를 명시한다.
3. 1순위에 대해 한 문장 질문, 제작 시점성, 새로 설명할 것, 검증 가설 2~3개, 확인할 핵심 사실 5개, 최대 위험을 작성한다.
4. 사용자 승인 전에는 딥리서치를 시작한 것으로 간주하지 않는다.
