# 1km 아이템 발굴

## 필수 참고

작업 전에 [references/item-discovery-guide.md](references/item-discovery-guide.md)를 읽고 아이템 범위, 랭킹 근거, 제외 기준을 적용한다.

## 절차

1. 조사 기준 시각과 최근 탐색 범위를 KST로 고정한다.
2. 최신 정보가 필요하므로 웹을 확인한다. 네이버 언론사별 랭킹, 네이트 랭킹뉴스, 다음 뉴스 랭킹을 우선 탐색하고 커뮤니티 반응을 보조 신호로 확인한다.
3. 랭킹 페이지가 `robots.txt`, 로그인, 동적 렌더링, 지역·세션 제한으로 열리지 않으면 한 차례 다른 접근 경로를 시도한다. 대화형 브라우저가 있으면 직접 페이지 확인을 시도하되 우회 접속이나 차단 회피는 하지 않는다.
4. 끝내 열리지 않은 서비스는 `접근 제한`으로 기록한다. 해당 서비스의 일반 뉴스 검색 결과는 후보 발견에 사용할 수 있지만 랭킹 확인으로 표기하지 않는다.
5. 정당·선거·정치인·이념 공방을 중심으로 한 후보를 즉시 제외한다.
6. 같은 사건을 하나의 이슈로 묶고, 직접 확인한 랭킹은 서비스·종류·순위·확인시각·랭킹 페이지 URL을 기록한다.
7. 화제성, 궁금증, 지속성, 설명 가치, 7~9분 확장성, 영상화 가능성을 판단한다.
8. 단순 사건·가십·확인되지 않은 캡처를 제외한다.
9. 서로 다른 분야를 고려해 후보 10개를 순위로 제시한다.

## 규칙

- 커뮤니티 게시물은 화제 발견용으로만 사용하고 사실은 독립 출처로 확인한다.
- 직접 확인한 랭킹 후보의 링크는 개별 기사 원문이 아니라 후보가 올라간 랭킹 페이지로 연결한다.
- 랭킹 후보에는 서비스, 랭킹 종류, 실제 순위, 기사 제목, KST 확인시각을 함께 적는다.
- 날짜별 랭킹 주소가 있으면 해당 날짜 주소를 사용한다.
- 접근 가능한 랭킹만으로 10개를 채우지 못하면 일반뉴스·커뮤니티 발견 후보를 보조 후보로 섞을 수 있다. 이때 `랭킹 미확인`을 명시하고 기사 원문을 연결하며 순위를 만들지 않는다.
- 기사 원문과 공식자료 링크는 아이템 선정 이후 딥리서치 단계에서 수집한다.
- 기사 순위를 그대로 복사하지 말고 1km가 설명할 질문으로 다시 정의한다.
- 랭킹 접근 실패를 기사 부재나 랭킹 부재로 해석하지 않는다.
- 정보 확인이 불가능하면 추정으로 채우지 말고 제한을 명시한다.
