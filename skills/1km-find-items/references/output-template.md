링크는 개별 기사 원문이 아니라 해당 기사가 올라간 네이버·네이트·다음 뉴스 랭킹 페이지로 연결한다. 사용자가 랭킹 페이지에서 동일한 기사 제목과 순위를 확인할 수 있게 한다.

랭킹 페이지를 직접 확인하지 못한 보조 후보는 `랭킹 미확인·일반뉴스 검색`으로 표시하고 기사 원문을 연결한다. 랭킹 후보와 섞어 쓸 때도 확인하지 않은 순위를 만들지 않는다.

- 조사 기준: YYYY-MM-DD HH:MM KST
- 탐색 범위: 최근 N일
- 정치 제외 확인: 완료/미완료
- 중복 통합 내역:
- 서비스별 접근 상태와 제한 사유:
- 랭킹에서 확인하지 못해 보조 후보로 분리한 항목:

## 즉시 추천 3개

각 후보에 추천 이유 두 문장과 지금 제작할 때의 위험 한 문장을 적는다.
