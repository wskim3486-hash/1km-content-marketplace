# 4단계: 대본 작성 전 1차 팩트체크 검증표

버전: 1.1

## 목적

딥리서치에 담긴 핵심 주장·수치·인용·인과관계를 구성안과 대본의 재료로 사용할 수 있는 수준인지 검증한다. 완성 대본에는 7단계 사후 팩트체크를 별도로 실시한다.

## 검증 등급

- A 확정: 1차 출처와 독립적인 추가 출처가 일치한다.
- B 사용 가능: 신뢰도 높은 단일 1차 출처이거나 복수의 2차 출처가 일치한다. 범위를 제한해 표현한다.
- C 보류: 일부 근거만 있거나 출처 간 충돌이 해결되지 않았다.
- D 사용 금지: 원출처 부재, 사실 오류, 과장, 날짜·단위 오류가 있다.

## 2회 이상 검증 원칙

핵심 주장에는 서로 독립적인 출처 두 개를 붙인다. 같은 보도자료를 받아쓴 기사 여러 개는 한 개 출처로 센다. 가장 좋은 조합은 `원자료/공식자료 + 독립 취재·연구`다.

## 항목별 확인

### 숫자

- 기준 시점, 기간, 단위, 모수, 명목·실질, 평균·중앙값을 구분한다.
- 서로 다른 조사·표본의 숫자를 단순 비교하지 않는다.
- 퍼센트와 퍼센트포인트를 구분한다.

### 인용

- 원문 맥락과 의미가 같은지 확인한다.
- 번역 인용은 원문과 번역을 함께 보관한다.
- 익명 커뮤니티 발언은 사실 근거가 아니라 반응 사례로만 쓴다.

### 인과관계

- 함께 나타났다는 이유만으로 원인이라고 단정하지 않는다.
- 연구가 상관관계만 보여주면 그 수준으로 표현한다.
- 복합 원인은 하나의 이유로 단순화하지 않는다.

### 시점

- “최근”, “현재”, “역대”는 구체적 날짜와 비교 범위를 확인한다.
- 오래된 기사나 통계를 현재 상황으로 말하지 않는다.

### 법적·윤리적 위험

- 실명·업체명·얼굴·게시물 캡처의 필요성과 공개 범위를 확인한다.
- 범죄·의혹은 수사·재판 단계와 당사자 반론을 함께 적는다.
- 미성년자·개인정보는 최소화한다.

### 생활 장면과 사례

- 실제 사례는 인물·상황·시점·출처와 대표성 한계를 확인한다.
- 복수 사례를 합친 장면은 `[재구성]`, 계산을 위한 상황은 `[가상예시]`로 표시한다.
- 확인하지 않은 직접인용, 가족관계, 직장, 감정, 시간·장소를 사실처럼 추가하지 않는다.
- 사실관계가 아닌 보편적 일상 묘사는 과장 없이 쓰고 특정 집단 전체로 일반화하지 않는다.
