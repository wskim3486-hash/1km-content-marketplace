# 1km 대본 작성 전 1차 팩트체크

## 필수 참고

검증 전에 [references/pre-script-fact-check-guide.md](references/pre-script-fact-check-guide.md)를 읽고 주장 분해, 이중 검증, 방송 가능 표현 기준을 적용한다.

## 절차

1. 검증 대상 문서에서 사실로 들리는 문장을 원자 단위 주장으로 분해한다.
2. 핵심·보조 중요도를 표시하고 F01부터 ID를 부여한다.
3. 웹에서 원문과 원자료를 확인한다.
4. 핵심 주장마다 서로 독립적인 출처 두 개를 확보한다. 같은 원자료를 재인용한 기사는 하나로 센다.
5. 숫자의 기준일·기간·단위·모수·평균/중앙값·퍼센트/퍼센트포인트를 확인한다.
6. 인용의 원문 맥락, 번역, 발언 시점을 확인한다.
7. 상관관계를 인과관계로 확대했는지 확인한다.
8. 반대 근거와 예외를 확인하고 허용 표현을 정한다.
9. 대본 후보로 넘길 생활 장면의 출처·대표성·유형 표시를 확인한다. 실제 인물의 말·감정·관계를 확보하지 않았다면 실제 사례처럼 쓰지 못하게 한다.

## 등급

[references/verification-table.md](references/verification-table.md)의 A~D 등급을 적용한다. C는 추가 확인 전 사실처럼 쓰지 말고, D는 제거한다.

## 출력

주장별 검증표, 생활 장면 검증 결과, 수정 기록, 사용 가능한 팩트 ID 목록, 미해결 위험, 검증 기준 시각을 제시한다. 출처가 부족하면 그 사실을 명시하고 추정으로 채우지 않는다.

이 검증 결과는 구성안과 대본의 입력으로 사용한다. 대본 완성 후에는 별도의 `1km-script-fact-check`로 문장과 근거 링크를 다시 검증한다.
