# 7~9분 구성안

| 구간 | 권장 시간 | 역할 |
| --- | --- | --- |
| 콜드 오픈 | 0:00~0:25 | 공감과 이상함 |
| 질문 고정 | 0:25~0:55 | 질문과 시청 이유 |
| 현상 확인 | 0:55~2:00 | 사례와 규모 |
| 배경 확장 | 2:00~3:30 | 변화의 시작 |
| 원인 해부 | 3:30~5:30 | 원인 2~3개 |
| 반전·예외 | 5:30~6:40 | 단순 결론의 한계 |
| 해소 | 6:40~7:50 | 처음 질문의 답 |
| 생활 연결 | 7:50~9:00 | 의미와 관찰 포인트 |

| 구간·시간 | 장면 목적 | 핵심 내용 | 팩트 ID | 화면·그래픽 | 연결 장치·어미 리듬 |
| --- | --- | --- | --- | --- | --- |

핵심 멘트는 `설명(~다/~야) → 호응(~요/~죠) → 질문(~까/~냐)`처럼 기능에 따라 어미를 섞는다. `~습니다` 계열이 3문장 연속되는 설계는 수정한다.

## 리듬 설계

- 선택한 생활 공감 장면 2~3개와 유형·팩트 ID:
- 방송 핵심 숫자 최대 3개와 쉬운 생활 번역:
- 통계·분석 블록 연속 여부와 수정 결과:
- AI 쉬어가기 ① 진입 질문 / 웃음 기능 / 복귀 멘트:
- AI 쉬어가기 ② 진입 질문 / 웃음 기능 / 복귀 멘트:
