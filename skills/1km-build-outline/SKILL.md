# 1km 구성안 작성

## 필수 참고

설계 전에 [references/outline-guide.md](references/outline-guide.md)를 읽고 7~9분 흐름, 장면 단위, 대화형 전환 기준을 적용한다.

## 입력 제한

검증된 팩트 ID와 승인된 취재노트만 사용한다. C·D 등급 주장이나 출처 없는 정보는 구성의 전제로 사용하지 않는다.

## 설계

1. 영상의 한 문장 질문과 한 문장 답을 먼저 적는다.
2. 30초 안에 익숙하지만 이상한 장면·사실로 공감을 만든다.
3. 1분 안에 오늘 풀 질문과 볼 이유를 고정한다.
4. 현상 확인 → 배경 확장 → 원인 2~3개 → 반례·예외 → 질문 해소 → 생활 연결 순으로 설계한다.
5. 각 장면에 목적, 팩트 ID, 화면, 전환 질문, 예상 시간을 붙인다.
6. 검증된 생활 공감 장면 2~3개를 골라 오프닝·중간·엔딩에 분산한다. 통계·분석 구간이 두 번 연속되면 그 사이에 장면, 진행자 반응, 쉬운 번역 중 하나를 둔다.
7. AI 쉬어가기 지점을 기본 2곳 설계한다. 직전 내용에서 자연스럽게 생기는 질문, 예상 웃음 기능, 본문 복귀 멘트를 적고 피해·사고·취약계층을 다루는 구간은 피한다.
8. 반복되는 정보와 핵심 질문에 기여하지 않는 배경을 삭제한다.

## 화법 방향

간다효 레퍼런스의 고유 표현을 복제하지 말고, 대화형 질문과 다음 궁금증을 선제적으로 받는 전개 기능만 참고한다. 설명은 `~다/~야`, 호응은 `~요/~죠`, 전환은 `~까/~냐`가 자연스럽게 섞이도록 핵심 멘트를 설계한다. `~습니다` 계열이 연속되는 뉴스 리포트형 구성안을 만들지 않는다.

## 출력

[references/outline-template.md](references/outline-template.md)를 사용한다. 기존 구간·표 순서는 유지한다. 구성안 승인 전에는 완성 대본을 작성하지 않는다.
