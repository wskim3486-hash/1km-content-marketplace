# 1km 대본 완성 후 2차 팩트체크

## 필수 참고

검증 전에 [references/post-script-fact-check-guide.md](references/post-script-fact-check-guide.md)를 읽고 문장별 판정, 링크 검증, 수정 후 재검증 기준을 적용한다.

## 입력

근거 링크와 팩트 ID가 포함된 완성 대본, 1차 팩트체크표, 출처표를 사용한다. 자료 중 하나라도 없으면 검증 가능한 범위를 밝히고 부족한 자료를 요청한다.

## 절차

1. 대본을 문장 단위로 나누고 사실처럼 들리는 문장에 S001부터 ID를 부여한다.
2. 각 문장을 기존 팩트 ID와 연결한다.
3. 연결된 근거 링크를 직접 열어 제목·기관·발행일·본문·표·원자료를 확인한다.
4. 대본 표현이 출처가 말하는 범위보다 강해지거나 넓어지지 않았는지 비교한다.
5. 숫자·날짜·비율·순위·금액·인용을 원문과 단위까지 대조한다.
6. 상관관계를 인과관계로 바꿨거나 개인 사례를 전체 현상으로 일반화했는지 확인한다.
7. 모든 `[화면]`·`[그래픽]` 바로 아래에 근거 링크가 있는지, 링크가 해당 멘트를 직접 뒷받침하는지 확인한다.
8. 검색 결과가 아니라 실제 공식자료·기사·게시물 원문 링크인지 확인한다.
9. 녹화일 기준으로 바뀔 수 있는 최신 정보를 다시 조사한다.
10. 실제사례·재구성·가상예시의 표시와 공개 방식이 1차 검증 결과와 맞는지 확인한다.
11. 촬영된 AI 답변을 사용할 경우 사실처럼 들리는 문장을 같은 기준으로 검증한다. 검증할 수 없는 AI 답변은 편집에서 제거한다.
12. 오류 문장을 수정하고 수정본을 같은 절차로 재검증한다.

## 판정

[references/post-script-verification.md](references/post-script-verification.md)의 형식과 판정을 사용한다.

- `PASS`: 출처와 문장이 정확히 일치하고 링크가 정상 작동한다.
- `REVISE`: 근거는 있으나 과장·누락·맥락·단위 오류가 있어 수정해야 한다.
- `HOLD`: 출처 충돌 또는 최신성 문제로 추가 확인이 필요하다.
- `REMOVE`: 근거가 없거나 사실과 달라 삭제해야 한다.

## 통과 조건

모든 사실 문장이 PASS이고 모든 화면·그래픽 링크가 해당 주장을 직접 뒷받침해야 한다. REVISE는 수정 후 다시 검증하고 HOLD·REMOVE가 남아 있으면 최종검수 단계로 넘기지 않는다.
