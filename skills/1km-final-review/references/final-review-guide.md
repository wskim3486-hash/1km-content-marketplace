# 8단계: 최종검수 및 촬영 인계서

버전: 1.2

## 목적

2차 팩트체크를 통과한 완성 대본을 논리·낭독·화면·법적 위험 관점에서 검수하고, 기자와 편집자가 바로 제작할 수 있는 상태로 인계한다.

## 1. 사실 검수

- [ ] `07A_대본_사후_팩트체크_검증표`가 PASS 또는 수정완료 상태다.
- [ ] 대본의 모든 사실 문장에 팩트 ID가 있다.
- [ ] 핵심 주장은 팩트체크 A 또는 B 등급이다.
- [ ] 숫자의 시점·단위·모수가 멘트 또는 자막으로 드러난다.
- [ ] 인용은 원문 의미와 같다.
- [ ] 사실·해석·사례가 혼동되지 않는다.
- [ ] 기준일 이후 바뀔 수 있는 내용은 녹화 직전에 재확인한다.

## 2. 논리·구성 검수

- [ ] 오프닝과 결론이 같은 질문을 다룬다.
- [ ] 원인과 단순 동시 발생을 구분한다.
- [ ] 반론·예외가 적절히 포함됐다.
- [ ] 같은 정보가 반복되지 않는다.
- [ ] 불필요한 역사·배경이 핵심 흐름을 막지 않는다.

## 3. 낭독 검수

- [ ] 기자가 전체 대본을 소리 내 읽고 시간을 쟀다.
- [ ] 숨이 차는 긴 문장을 나눴다.
- [ ] 기관명·외래어·숫자 발음을 확인했다.
- [ ] 말로 들었을 때 지시어의 대상이 분명하다.
- [ ] 억지 유행어·반복 말버릇을 줄였다.
- [ ] 대화형 종결이 전체 낭독 문장의 70% 이상이다.
- [ ] `~습니다/~입니다/~합니다/~됩니다` 계열이 전체의 20%를 넘지 않는다.
- [ ] `~습니다` 계열 또는 같은 종결어미가 3문장 연속 나오지 않는다.
- [ ] `~다/~야`가 시청자를 낮추는 직접 반말이나 명령으로 쓰이지 않았다.
- [ ] 첫 30초 안에 질문과 반응·반전이 각각 한 번 이상 있다.
- [ ] 정보 설명만 이어지는 구간이 45초를 넘지 않는다.
- [ ] 3~6문장마다 질문·반응·반론·발견 중 하나가 자연스럽게 들어간다.
- [ ] 같은 추임새·접속 장치를 90초 안에 반복하지 않는다.
- [ ] 감탄사와 추임새 뒤에 새 정보·질문·반론이 이어진다.
- [ ] 진행자의 감정이 중대한 피해·사고·취약한 당사자를 희화화하지 않는다.
- [ ] 통계·분석 문단이 두 개 연속되지 않는다.
- [ ] 검증된 생활 공감 장면 2~3개가 서로 다른 구간에 배치됐다.
- [ ] AI 쉬어가기의 질문과 복귀 멘트가 본문 흐름에 자연스럽게 붙는다.
- [ ] AI 대화는 회당 10~20초, 전체 40초 이내이며 설명을 대신하지 않는다.
- [ ] AI 농담이 사람·피해·취약성을 향하지 않고 실제 촬영 답변의 사실 문장이 검증됐다.

## 4. 화면·편집 검수

- [ ] 각 핵심 문장에 화면 계획이 있다.
- [ ] 모든 `[화면]`·`[그래픽]` 지시 바로 아래에 근거 링크가 있다.
- [ ] 근거 링크가 실제 자료 또는 기사 원문으로 열린다.
- [ ] 통계 그래픽의 축·단위·출처가 정확하다.
- [ ] 기사 캡처는 필요한 부분만 사용하고 출처를 표시한다.
- [ ] 인터뷰·아카이브·이미지의 사용 권리를 확인한다.
- [ ] 같은 화면 유형이 장시간 반복되지 않는다.

## 5. 법적·윤리 검수

- [ ] 개인 신상과 미성년자 정보 노출을 최소화했다.
- [ ] 의혹·분쟁에는 당사자 입장과 현재 절차를 반영했다.
- [ ] 특정 업체·개인을 일반화하거나 조롱하지 않는다.
- [ ] 게시물 캡처의 닉네임·사진·연락처를 필요한 만큼 가렸다.

## 수정 우선순위

- P0 녹화 금지: 사실 오류, 명예훼손·개인정보 위험, 출처 없음
- P1 반드시 수정: 논리 비약, 핵심 질문 미해소, 중대한 오해 가능
- P2 개선 권장: 문장 길이, 반복, 화면 단조로움
- P2 개선 권장: 대화형 종결 비율 부족, 같은 어미 반복, 기자 리포트체
- P2 개선 권장: 45초 이상 설명 독주, 상호작용 비트 부족, 추임새 반복·과잉
- P2 개선 권장: 통계 과밀, 생활 장면 부족, AI 대화의 억지스러운 진입·복귀 또는 과도한 분량
- P3 선택: 취향·리듬·세부 표현

## 촬영 인계서 양식

- 콘텐츠 가제:
- 최종 질문과 답:
- 목표 러닝타임:
- 녹화일 / 게시 예정일:
- 출연 기자:
- 최종 대본 버전:
- 녹화 직전 재확인 항목:
- 발음·강조 주의:
- 생활 공감 장면과 유형 표시:
- AI 쉬어가기 삽입 위치 / 질문 / 복귀 멘트 / 대체 편집안:
- 촬영된 AI 답변 2차 검증 상태:
- 필수 화면 자료:
- 미확보 화면·인터뷰:
- 그래픽 제작 목록:
- 법적·권리 확인 상태:
- 2차 팩트체크 결과 / 확인 시각:
- 최종 승인자 / 승인 시각:

## 최종 판정

- `GO`: 녹화 가능
- `CONDITIONAL GO`: 표시된 P1 수정 후 녹화 가능
- `HOLD`: 추가 취재 또는 팩트체크 필요
- `DROP`: 제작 중단

2차 팩트체크가 완료되지 않았거나 `REVISE`·`HOLD`·`REMOVE` 항목이 남아 있으면 `GO`를 부여하지 않는다.
