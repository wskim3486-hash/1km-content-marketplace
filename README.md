# 1km 콘텐츠 제작 플러그인

뉴스와 이슈에서 아이템을 찾고,

**아이템 발굴 → 딥리서치 → 팩트체크 → 구성안 → 촬영 대본 → 최종검수**

까지 한 번에 진행하는 **1km 유튜브 콘텐츠 제작용 AI 플러그인**입니다.

코딩을 몰라도 사용할 수 있습니다.

처음 사용하는 분은 아래 순서대로만 따라 하세요.

---

# 가장 쉬운 설치 방법

## 1. ChatGPT 데스크톱 앱 설치

먼저 컴퓨터에 **ChatGPT 데스크톱 앱**을 설치합니다.

Windows용 ChatGPT 앱에는

- Chat
- Work
- Codex

가 함께 들어 있습니다.

### 설치 방법

1. 인터넷에서 **ChatGPT 공식 홈페이지**에 접속합니다.
2. Windows용 **ChatGPT 데스크톱 앱**을 다운로드합니다.
3. 설치가 끝나면 ChatGPT 앱을 실행합니다.
4. 본인의 ChatGPT 계정으로 로그인합니다.

> 이미 최신 ChatGPT 데스크톱 앱이 설치되어 있다면 이 단계는 건너뛰면 됩니다.

---

# 2. Codex 열기

ChatGPT 앱을 실행합니다.

왼쪽 위 메뉴에서 **Codex**를 선택합니다.

그리고 **새 작업(New Task)** 을 하나 만듭니다.

처음 Codex를 실행하면 컴퓨터 폴더나 작업 위치를 선택하라는 화면이 나올 수 있습니다.

특별히 작업할 폴더가 없다면 새 폴더를 하나 만들어 선택해도 됩니다.

예:

```text
문서
└─ 1km
```

폴더 이름은 아무거나 사용해도 됩니다.

---

# 3. 1km 플러그인 설치

Codex의 새 작업창에 아래 문장을 **통째로 복사해서 붙여넣습니다.**

```text
아래 GitHub 저장소를 Codex 플러그인 마켓플레이스로 등록하고,
그 안의 1km-content-production 플러그인을 설치해줘.

설치가 끝나면 정상적으로 설치되었는지도 확인해줘.

https://github.com/wskim3486-hash/1km-content-marketplace.git
```

그리고 Enter를 누릅니다.

끝입니다.

직접 파일을 다운로드하거나 압축을 풀 필요가 없습니다.

GitHub 사용법을 몰라도 됩니다.

코드를 입력할 필요도 없습니다.

---

# 4. 설치 중 허용 창이 나오면

Codex가 설치 작업을 하면서

- 명령어 실행
- 파일 접근
- GitHub 저장소 접근

등의 허용 여부를 물어볼 수 있습니다.

이 플러그인을 설치하기 위한 작업이라면 **허용(Allow)** 을 눌러 진행하면 됩니다.

Codex가 설치를 완료할 때까지 안내에 따라 진행합니다.

---

# 5. 설치 완료 확인

Codex가 설치를 완료했다고 알려주면 현재 작업을 닫습니다.

그리고 **새 작업**을 하나 다시 만듭니다.

새 작업에서 다음처럼 물어봐도 됩니다.

```text
1km 콘텐츠 제작 플러그인이 정상적으로 설치되어 있는지 확인해줘.
```

정상적으로 설치되어 있다면 이제 준비가 끝난 것입니다.

---

# 이제부터 사용하는 방법

플러그인은 **한 번만 설치하면 됩니다.**

앞으로 매번 GitHub 주소를 입력하거나 다시 설치할 필요가 없습니다.

Codex에서 새 작업을 열고 원하는 작업을 그냥 말하면 됩니다.

---

## 방법 1. 아이템부터 찾아달라고 하기

아직 어떤 주제로 영상을 만들지 정하지 않았다면:

```text
오늘 1km 콘텐츠로 만들 만한 비정치 아이템 10개를 찾아줘.
```

이렇게 요청하면 됩니다.

---

## 방법 2. 특정 분야에서 아이템 찾기

예를 들어 부동산 관련 콘텐츠를 만들고 싶다면:

```text
주제는 부동산이야.

1km 콘텐츠에 적합한 아이템 10개를 찾아서
가장 좋은 아이템까지 선정해줘.
```

IT 분야라면:

```text
주제는 IT야.

최근 이슈를 조사해서
1km 콘텐츠로 만들 만한 아이템 10개를 찾아줘.
```

---

## 방법 3. 가지고 있는 기사로 바로 제작하기

이미 다루고 싶은 기사가 있다면 기사 주소와 함께 요청하면 됩니다.

```text
이 기사로 1km 전체 제작 프로세스를 진행해줘.

기사:
여기에 기사 주소 붙여넣기
```

---

# 전체 제작을 맡기고 싶다면

가장 간단한 요청은 이것입니다.

```text
1km 전체 제작 프로세스를 진행해줘.
아이템 선택도 맡길게.
```

필요하면 주제만 추가하면 됩니다.

```text
주제는 부동산이야.

1km 전체 제작 프로세스를 진행해줘.
아이템 선택도 맡길게.
```

그러면 플러그인이 전체 제작 과정을 이어서 진행합니다.

---

# 1km 전체 제작 과정

전체 제작을 요청하면 기본적으로 다음 과정을 진행합니다.

### 1. 아이템 발굴

현재 사람들이 관심을 가지고 있는 뉴스와 이슈를 조사합니다.

### 2. 아이템 비교 및 선정

발굴한 후보들을 비교해서  
1km 콘텐츠에 가장 적합한 아이템을 선정합니다.

### 3. 딥리서치

선정한 기사와 핵심 질문을 중심으로 추가 자료를 조사합니다.

단순히 숫자와 통계를 나열하지 않고

- 사람들이 공감할 만한 사례
- 실제 생활과 연결되는 이야기
- 과거와 현재의 변화
- 예상 밖의 사실
- 반대 사례
- 앞으로의 변화

등을 함께 조사합니다.

### 4. 1차 팩트체크

대본을 쓰기 전에 핵심 사실과 수치를 다시 확인합니다.

### 5. 구성안

약 7~9분 분량의 영상이 자연스럽게 이어지도록 이야기 구조를 만듭니다.

### 6. 촬영 대본

뉴스 기사처럼 딱딱하게 읽는 글이 아니라  
실제로 사람이 카메라 앞에서 이야기하는 것처럼 대본을 작성합니다.

### 7. 2차 팩트체크

완성된 대본에 들어간

- 숫자
- 날짜
- 인물
- 기업
- 정책
- 조사 결과
- 인용
- 주요 주장

등을 다시 확인합니다.

### 8. 최종검수

촬영에 바로 사용할 수 있는 상태인지 마지막으로 확인합니다.

# 꼭 전체 과정을 돌릴 필요는 없습니다

필요한 부분만 요청해도 됩니다.

예:

```text
아이템 10개만 찾아줘.
```

```text
이 기사 딥리서치까지만 진행해줘.
```

```text
구성안까지만 만들어줘.
```

```text
이 내용으로 촬영 대본만 작성해줘.
```

```text
이 대본 팩트체크해줘.
```

자연스럽게 말하면 플러그인이 필요한 작업을 판단해서 진행합니다.

---

# 설치는 한 번만

중요합니다.

**1km 플러그인은 컴퓨터마다 처음 한 번만 설치하면 됩니다.**

매번 콘텐츠를 만들 때마다 설치하는 것이 아닙니다.

설치 후에는 Codex에서 새 작업을 열고 평소처럼 요청하면 됩니다.

---

# 설치가 안 될 때

대부분은 위의 방법으로 설치할 수 있습니다.

그래도 설치되지 않는 경우에만 아래 방법을 사용하세요.

## 방법 1. Codex에게 다시 설치 요청

새 작업을 만들고 아래 내용을 입력합니다.

```text
1km-content-production 플러그인 설치 상태를 확인해줘.

설치되어 있지 않으면 아래 GitHub 저장소를
Codex 플러그인 마켓플레이스로 등록하고 설치해줘.

https://github.com/wskim3486-hash/1km-content-marketplace.git
```

---

# 그래도 안 될 때: 터미널 설치

이 방법은 위 방법으로 설치되지 않을 때만 사용하세요.

먼저 Windows에서 **터미널**을 실행합니다.

### 터미널 여는 방법

키보드에서

```text
Windows 키
```

를 누른 뒤

```text
터미널
```

또는

```text
Terminal
```

을 검색합니다.

**Windows Terminal**을 실행합니다.

관리자 권한으로 실행할 필요는 없습니다.

---

## Codex 설치 여부 확인

터미널에 아래 명령을 입력합니다.

```powershell
codex --version
```

버전 번호가 나오면 Codex가 정상적으로 설치되어 있는 것입니다.

예:

```text
codex-cli 0.xxx.x
```

---

## 플러그인 설치

아래 명령을 **한 줄씩** 입력합니다.

첫 번째:

```powershell
codex plugin marketplace add wskim3486-hash/1km-content-marketplace
```

Enter를 누릅니다.

그다음 두 번째:

```powershell
codex plugin add 1km-content-production@1km-content-marketplace
```

Enter를 누릅니다.

설치가 완료되면 ChatGPT/Codex에서 새로운 작업을 열어 사용합니다.

---

# `codex` 명령을 찾을 수 없다고 나오는 경우

다음과 비슷한 메시지가 나오면

```text
'codex' is not recognized
```

또는

```text
codex 명령을 찾을 수 없습니다
```

Codex CLI가 설치되어 있지 않은 것입니다.

이 경우 **터미널 설치 방법을 계속 진행하지 말고**, 위에서 설명한 **ChatGPT 데스크톱 앱의 Codex에서 설치하는 방법을 먼저 사용하세요.**

일반 사용자는 터미널을 사용할 필요가 없습니다.

# 업데이트

플러그인이 업데이트되었을 때도 가장 쉬운 방법은 Codex에게 맡기는 것입니다.

Codex 새 작업에서 다음과 같이 요청하세요.

```text
1km-content-production 플러그인을
최신 버전으로 업데이트해줘.

GitHub 저장소:
https://github.com/wskim3486-hash/1km-content-marketplace.git

업데이트가 끝나면 현재 설치 버전도 확인해줘.
```

업데이트가 끝나면 사용 중인 작업을 닫고 **새 작업**을 만들어 사용하는 것을 권장합니다.
